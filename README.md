# Titanic-survival-prediction-using-different-types-of-supervised-classification-algorithms

🚢 Titanic Survival Prediction

This project predicts whether a passenger survived the Titanic disaster using the built-in Titanic dataset from Seaborn (sns.load_dataset("titanic")). Different supervised machine learning classification algorithms are used and compared to find the best model.

## Project Highlights

1. Dataset loaded using: df = sns.load_dataset("titanic").
2. Performed data cleaning (handling missing values like age, embarked, deck, etc.).
3. Applied feature encoding (Label Encoding, One-Hot Encoding).
4.Used feature scaling where necessary.
5.Trained multiple supervised classification models, including:
    i. Logistic Regression.
    ii. Decision Tree.
    iii. Random Forest.
    iv. K-Nearest Neighbors (KNN).
    v. Support Vector Machine (SVM).
    vi. Naive Bayes.
